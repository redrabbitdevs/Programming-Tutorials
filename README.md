# Programming Tutorials

A comprehensive, open site that teaches programming from beginner to expert, across every programming language and up to each language's latest version. Python comes first.

- `site/`: the Astro website
- `research/`: sourced fact sheets and curriculum outlines for each language
- `examples/`: runnable code examples, executed by the Validator
- `.orchestration/`: team workflow, state and reviews (see `RESUME.md` to continue work)
- `.claude/agents/`: teammate role definitions
