  GitHub by monthly contributors (about 2.64M, +66.6% YoY).
- Python is #2 (about +850k contributors, +48.8% YoY) and remains the top language for AI and data
  science repositories.
- JavaScript is #3 (about +427k contributors, +24.8% YoY).
