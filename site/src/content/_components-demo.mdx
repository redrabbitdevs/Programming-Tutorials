## Your first program

Save this as `hello.py` and run it with `python3 hello.py`.

```python title="hello.py"
name = "world"
print(f"Hello, {name}!")
```

The program prints:

```text
Hello, world!
```

## Version markers

Some features only exist from a given release. A marker like <Since v="3.10" /> sits beside the heading or sentence that needs it. Structural pattern matching, for example, needs 3.10 or later.

```python title="match_demo.py" {2}
def kind(value):
    match value:
        case int():
            return "integer"
        case str():
            return "text"
        case _:
            return "something else"

print(kind(3))
print(kind("three"))
```

## Try it

<Exercise title="Change the greeting">

Edit `hello.py` so that it prints `Hello, Ada!` on one line and `Welcome to Python.` on the next.

<Solution>

```python title="hello.py"
name = "Ada"
print(f"Hello, {name}!")
print("Welcome to Python.")
```

Each call to `print` ends its output with a newline, so two calls give two lines.

</Solution>
