A linked list gives each node one successor. Let a node point to several others and you can describe far more: folders inside folders, a family's ancestors, the road network of a country, the friendships on a social site. The two shapes you will meet are **trees**, which have a clear top and no loops, and **graphs**, which are the general case.

## Trees

A **tree** is a set of nodes connected so that there is exactly one path between any two. One node is the **root**, at the top. Every other node has exactly one **parent** (the node above it) and may have any number of **children** (the nodes directly below). A node with no children is a **leaf**. The **height** is the number of levels from the root down to the deepest leaf.

```text
        5            root: 5
       / \           5 has children 3 and 8
      3   8          1, 4, 7, 9 are leaves
     / \ / \         height: 3 levels
    1  4 7  9
```

Trees are everywhere: a file system, the structure of an HTML page, the grammar of a program, the decisions in a game. Because each subtree is itself a tree, [recursion](../recursion/) is the natural way to process them: handle the node, then recurse into each child.

### Binary search trees

A **binary tree** gives each node at most two children, called left and right. A **binary search tree** (BST) adds one rule that makes searching quick: for every node, everything in its left subtree is smaller, and everything in its right subtree is larger.

To find a value, compare it with the current node. If it is smaller go left, if larger go right, and if equal you have found it. Each step discards a whole subtree. In a reasonably balanced tree of a million values, you need about twenty comparisons rather than a million.

Reading the tree in **in-order** (left subtree, then the node, then the right subtree) produces the values in sorted order, which is a handy way to check you got the rule right.

```c title="bst.c"
    int value;
    struct Node *left;
    struct Node *right;

Node *insert(Node *node, int value) {
    if (node == NULL) {
        Node *n = calloc(1, sizeof *n);   /* zeroed, so left and right start as NULL */
        n->value = value;
        return n;
    }
    if (value < node->value) node->left = insert(node->left, value);
    else if (value > node->value) node->right = insert(node->right, value);
    return node;                          /* equal values are ignored */
}

int contains(const Node *node, int value) {
    if (node == NULL) return 0;
    if (value == node->value) return 1;
    return contains(value < node->value ? node->left : node->right, value);
}

void in_order(const Node *node) {
    if (node != NULL) {
        in_order(node->left);             /* left subtree */
        printf(" %d", node->value);       /* the node itself */
        in_order(node->right);            /* right subtree */
    }
}

int height(const Node *node) {
    if (node == NULL) return 0;
    int l = height(node->left), r = height(node->right);
    return 1 + (l > r ? l : r);
}

void free_tree(Node *node) {
    if (node != NULL) {
        free_tree(node->left);
        free_tree(node->right);
        free(node);
    }
}
```

Every function has the recursive shape from the earlier lesson: a base case (the empty tree, `None`/`null`) and a recursive case on a smaller tree.

A BST is quick only while it stays reasonably balanced. If you insert already-sorted values (1, 2, 3, 4, ...) every node goes to the right and the "tree" degenerates into a linked list, with searches as slow as one. Real libraries use self-balancing variants to prevent this.

## Graphs

A **graph** is a set of **nodes** (also called *vertices*) joined by **edges**. Unlike a tree, a graph may have loops, several routes between two nodes, and no root. If an edge can be followed only one way (a one-way street) the graph is **directed**; if it works both ways (a friendship) it is **undirected**. Maps, networks, dependency lists and game boards are all graphs.

The most common way to store one is an **adjacency list**: a map from each node to the list of its neighbours.

```text
A --- B
|     |
C --- D --- E

A: [B, C]
B: [A, D]
C: [A, D]
D: [B, C, E]
E: [D]
```

Because the graph is undirected, each edge is written twice, once in each direction. For a dense graph, an alternative is an adjacency **matrix** (a grid saying whether node *i* connects to node *j*), which wastes space when most pairs are not connected.

## Searching a graph

Two basic strategies, differing only in the structure they use to remember where to go next:

- **Breadth-first search (BFS)** explores outward in rings: all nodes one step from the start, then all nodes two steps away, and so on. It uses a **queue**. Because it reaches nodes in order of distance, the first time it reaches the goal is along a **shortest path** (fewest edges).
- **Depth-first search (DFS)** goes as deep as it can along one route before backing up and trying another. It uses a **stack**, or equivalently recursion. It is natural for questions like "can I reach this node?", "is there a cycle?" and "explore every possibility".

Both must remember which nodes they have **visited**. In a graph with loops, without that record the search would circle forever.

Here is BFS finding the shortest path from A to E in the graph above. Alongside the queue it keeps a `parents` record: for each node reached, the node we came from. Once we reach the goal, we follow parents backwards to rebuild the route.

<Tab label="Python">

```python title="graph_bfs.py"
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"],
}


def shortest_path(graph, start, goal):
    parents = {start: None}            # also serves as the visited set
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == goal:
            break
        for neighbour in graph[node]:
            if neighbour not in parents:
                parents[neighbour] = node
                queue.append(neighbour)
    if goal not in parents:
        return None                    # unreachable
    path = []
    node = goal
    while node is not None:            # walk back to the start
        path.append(node)
        node = parents[node]
    return path[::-1]


path = shortest_path(graph, "A", "E")
print("shortest path:", " -> ".join(path))
print("steps:", len(path) - 1)
```

```javascript title="graph_bfs.js"
const graph = {
  A: ["B", "C"],
  B: ["A", "D"],
  C: ["A", "D"],
  D: ["B", "C", "E"],
  E: ["D"],
};

function shortestPath(graph, start, goal) {
  const parents = new Map([[start, null]]); // also serves as the visited set
  const queue = [start];
  while (queue.length > 0) {
    const node = queue.shift();
    if (node === goal) break;
    for (const neighbour of graph[node]) {
      if (!parents.has(neighbour)) {
        parents.set(neighbour, node);
        queue.push(neighbour);
      }
    }
  }
  if (!parents.has(goal)) return null; // unreachable
  const path = [];
  for (let node = goal; node !== null; node = parents.get(node)) { // walk back
    path.push(node);
  }
  return path.reverse();
}

const path = shortestPath(graph, "A", "E");
console.log("shortest path:", path.join(" -> "));
console.log("steps:", path.length - 1);
```

```java title="GraphBfs.java"
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.LinkedList;
import java.util.List;
import java.util.Map;

public class GraphBfs {
    static List<String> shortestPath(Map<String, List<String>> graph, String start, String goal) {
        Map<String, String> parents = new HashMap<>();   // also serves as the visited set
        parents.put(start, null);
        Deque<String> queue = new ArrayDeque<>();
        queue.add(start);
        while (!queue.isEmpty()) {
            String node = queue.poll();
            if (node.equals(goal)) break;
            for (String neighbour : graph.get(node)) {
                if (!parents.containsKey(neighbour)) {
                    parents.put(neighbour, node);
                    queue.add(neighbour);
                }
            }
        }
        if (!parents.containsKey(goal)) return null;     // unreachable
        LinkedList<String> path = new LinkedList<>();
        for (String node = goal; node != null; node = parents.get(node)) {  // walk back
            path.addFirst(node);
        }
        return path;
    }

    public static void main(String[] args) {
        Map<String, List<String>> graph = Map.of(
            "A", List.of("B", "C"),
            "B", List.of("A", "D"),
            "C", List.of("A", "D"),
            "D", List.of("B", "C", "E"),
            "E", List.of("D"));

        List<String> path = shortestPath(graph, "A", "E");
        System.out.println("shortest path: " + String.join(" -> ", path));
        System.out.println("steps: " + (path.size() - 1));
    }
}
```

```c title="graph_bfs.c"
#include <stdio.h>

#define N 5

int main(void) {
    /* Adjacency matrix: adj[i][j] is 1 when nodes i and j are joined.
       Nodes 0..4 stand for A..E. */
    int adj[N][N] = {
        {0, 1, 1, 0, 0},   /* A: B, C    */
        {1, 0, 0, 1, 0},   /* B: A, D    */
        {1, 0, 0, 1, 0},   /* C: A, D    */
        {0, 1, 1, 0, 1},   /* D: B, C, E */
        {0, 0, 0, 1, 0},   /* E: D       */
    };
    int start = 0, goal = 4;

    int parent[N];
    int visited[N] = {0};
    int queue[N], head = 0, tail = 0;

    for (int i = 0; i < N; i++) parent[i] = -1;
    visited[start] = 1;
    queue[tail++] = start;

    while (head < tail) {
        int node = queue[head++];
        if (node == goal) break;
        for (int next = 0; next < N; next++) {
            if (adj[node][next] && !visited[next]) {
                visited[next] = 1;
                parent[next] = node;
                queue[tail++] = next;
            }
        }
    }

    if (!visited[goal]) {
        printf("unreachable\n");
        return 0;
    }

    int path[N], length = 0;
    for (int node = goal; node != -1; node = parent[node]) {   /* walk back */
        path[length++] = node;
    }

    printf("shortest path: ");
    for (int i = length - 1; i >= 0; i--) {
        printf("%c%s", 'A' + path[i], i > 0 ? " -> " : "\n");
    }
    printf("steps: %d\n", length - 1);
    return 0;
}
```

### Depth-first search

Depth-first search on the same graph is shorter when written recursively, because the call stack does the remembering. The `visited` record is what stops A and B bouncing between each other forever.

## Common pitfalls

- **No visited record in a graph search.** If the graph has a loop, the search never ends. Trees cannot loop, so tree traversals do not need one.
- **Confusing the two searches.** BFS uses a queue and finds shortest paths in unweighted graphs; DFS uses a stack or recursion and does not.
- **Forgetting both directions** when building an undirected adjacency list, which leaves some nodes unreachable.
- **Assuming a BST is always fast.** Inserting sorted data into a plain BST produces a lopsided tree with list-like speed.
- **Forgetting the empty case.** Every tree function needs a base case for an empty (null) tree.
- **Shortest in steps is not shortest in distance.** BFS counts edges. If edges have lengths (kilometres), you need other algorithms.

<Exercise title="Shortest path through a maze">

A maze is a grid where `#` is a wall, `.` is open floor, `S` is the start and `E` is the exit. Moves go up, down, left or right. Print the least number of moves from `S` to `E`. The maze is:

```text
S.#.....
.##.###.
...#...E
.#...#..
```

Expected output: `moves: 11`.

<Solution>

Treat each open cell as a graph node whose neighbours are the open cells next to it, and run BFS from the start, remembering each cell's distance. The first time BFS reaches `E`, that distance is the shortest.

<Tabs>
<Tab label="Python">

```python title="maze_bfs.py"
from collections import deque

maze = [
    "S.#.....",
    ".##.###.",
    "...#...E",
    ".#...#..",
]

rows, cols = len(maze), len(maze[0])
for r in range(rows):
    for c in range(cols):
        if maze[r][c] == "S":
            start = (r, c)

distance = {start: 0}
queue = deque([start])
answer = None
while queue:
    r, c = queue.popleft()
    if maze[r][c] == "E":
        answer = distance[(r, c)]
        break
    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
        nr, nc = r + dr, c + dc
        if 0 <= nr < rows and 0 <= nc < cols and maze[nr][nc] != "#" and (nr, nc) not in distance:
            distance[(nr, nc)] = distance[(r, c)] + 1
            queue.append((nr, nc))

print("moves:", answer)
```

```java title="MazeBfs.java"
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

public class MazeBfs {
    public static void main(String[] args) {
        String[] maze = {
            "S.#.....",
            ".##.###.",
            "...#...E",
            ".#...#..",
        };

        int rows = maze.length;
        int cols = maze[0].length();
        int[][] distance = new int[rows][cols];
        for (int[] row : distance) {
            Arrays.fill(row, -1);
        }
        Deque<int[]> queue = new ArrayDeque<>();

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (maze[r].charAt(c) == 'S') {
                    distance[r][c] = 0;
                    queue.add(new int[] {r, c});
                }
            }
        }

        int[][] moves = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        int answer = -1;
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0];
            int c = cell[1];
            if (maze[r].charAt(c) == 'E') {
                answer = distance[r][c];
                break;
            }
            for (int[] move : moves) {
                int nr = r + move[0];
                int nc = c + move[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && maze[nr].charAt(nc) != '#' && distance[nr][nc] == -1) {
                    distance[nr][nc] = distance[r][c] + 1;
                    queue.add(new int[] {nr, nc});
                }
            }
        }

        System.out.println("moves: " + answer);
    }
}
```

```c title="maze_bfs.c"
#include <stdio.h>

#define ROWS 4
#define COLS 8

int main(void) {
    const char *maze[ROWS] = {
        "S.#.....",
        ".##.###.",
        "...#...E",
        ".#...#..",
    };

    int distance[ROWS][COLS];
    int queue_r[ROWS * COLS], queue_c[ROWS * COLS];
    int head = 0, tail = 0;

    for (int r = 0; r < ROWS; r++) {
        for (int c = 0; c < COLS; c++) {
            distance[r][c] = -1;
            if (maze[r][c] == 'S') {
                distance[r][c] = 0;
                queue_r[tail] = r;
                queue_c[tail] = c;
                tail++;
            }
        }
    }

    int dr[] = {-1, 1, 0, 0};
    int dc[] = {0, 0, -1, 1};
    int answer = -1;
    while (head < tail) {
        int r = queue_r[head];
        int c = queue_c[head];
        head++;
        if (maze[r][c] == 'E') {
            answer = distance[r][c];
            break;
        }
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d];
            int nc = c + dc[d];
            if (nr >= 0 && nr < ROWS && nc >= 0 && nc < COLS
                    && maze[nr][nc] != '#' && distance[nr][nc] == -1) {
                distance[nr][nc] = distance[r][c] + 1;
                queue_r[tail] = nr;
                queue_c[tail] = nc;
                tail++;
            }
        }
    }

    printf("moves: %d\n", answer);
    return 0;
}
```

## Summary

- A tree has a root, parents, children and leaves; a binary search tree keeps smaller values left and larger right, so a search discards half the remaining tree at each step.
- A graph is nodes plus edges, usually stored as an adjacency list.
- BFS (a queue) explores by distance and finds shortest paths; DFS (a stack or recursion) follows one route to its end. Both need a visited record when loops are possible.
