Gluing strings together with `+` and `str()` gets untidy fast. An f-string lets you write the sentence you want and drop values into it, with fine control over how each value looks.

This lesson needs Python 3.12 or later only for the last section. Everything before it runs on 3.8 and up.

## Expressions in braces

Put an `f` before the opening quote. Anything inside `{}` is evaluated as a Python expression and its result is inserted.

```python title="fstring_basics.py"
name = "Ada"
print(f"Hello, {name}!")
print(f"2 + 3 is {2 + 3}")
print(f"{{literal braces}}")
```

```text
Hello, Ada!
2 + 3 is 5
{literal braces}
```

Use `{{` and `}}` when you want literal braces in the output.

## The format spec

After a colon inside the braces comes a **format spec**, a small language for presentation. Its general shape is `[align][sign][#][0][width][,][.precision][type]`. Here are the pieces you will use constantly, one group at a time.

Numbers first: thousands separators, decimal places and percentages.

```python title="fstring_numbers.py"
price = 1234.5
ratio = 0.256
print(f"{price:,.2f}")
print(f"{ratio:.1%}")
print(f"[{42:05d}]")
```

```text
1,234.50
25.6%
[00042]
```

`,.2f` means a thousands separator and 2 decimal places. `.1%` multiplies by 100 and adds `%`. `05d` pads an integer with zeros to width 5.

Alignment comes next. A number after the alignment character sets the width of the field:

```python title="fstring_align.py"
name = "Ada"
print(f"[{name:>8}]")
print(f"[{name:<8}]")
print(f"[{name:^8}]")
```

```text
[     Ada]
[Ada     ]
[  Ada   ]
```

`>` aligns right, `<` left and `^` centres. Numbers align right by default and text aligns left.

For other number bases, use a type letter:

```python title="fstring_bases.py"
print(f"{255:x}")
print(f"{255:#b}")
```

```text
ff
0b11111111
```

| Spec | Meaning | Example result |
|---|---|---|
| `>8`, `<8`, `^8` | Right, left or centre in a field 8 wide | `[     Ada]` |
| `05d` | Integer, padded with zeros to width 5 | `00042` |
| `,.2f` | Thousands separator, 2 decimal places | `1,234.50` |
| `.1%` | Multiply by 100, add `%` | `25.6%` |
| `x`, `#b` | Hexadecimal; binary with a `0b` prefix | `ff`, `0b11111111` |

## Debugging with = and !r

Adding `=` after an expression prints the expression text, then its value. It has worked since Python 3.8 and is the quickest way to inspect a value while you debug.

```python title="fstring_debug.py"
price = 1234.5
print(f"{price=}")
print(f"{2 + 3 = }")
```

```text
price=1234.5
2 + 3 = 5
```

`!r` applies `repr()` to the value, which shows quotes around strings and makes invisible characters visible. This is usually what you want in log messages and error text.

```python title="fstring_repr.py"
name = "Ada"
note = "two\nlines"
print(f"{name!r}")
print(f"{note!r}")
print(f"{note}")
```

```text
'Ada'
'two\nlines'
two
lines
```

Printing a value together with its name, as `{price=}` does, is called **print debugging**, and the loops module uses it to find bugs.

## Quotes and line breaks <Since v="3.12" />

Before Python 3.12 you could not reuse the surrounding quote character inside the braces, nor put a comment or newline in the expression. From 3.12 onwards (PEP 701) f-strings are part of the normal grammar, so all of that works.

```python title="fstring_312.py"
print(f"{len("Python")} letters")

report = f"""Total: {
    2 + 3
}"""
print(report)
```

```text
6 letters
Total: 5
```

The first line reuses the double quote inside the braces. On Python 3.11 or earlier, both examples would be a `SyntaxError`. Even on 3.12 and later, reusing the outer quote can make a line hard to read. Switching quote style, or computing the value on its own line first, is often clearer.

Replacement fields can also be **nested** inside the format spec, so that the width and precision come from variables. This is not new in 3.12, and it works on older versions as well.

```python title="fstring_nested.py"
width = 10
precision = 3
value = 3.14159265
print(f"{value:{width}.{precision}f}|")
```

```text
     3.142|
```

## Common pitfalls

- **Forgetting the `f`.** `"Hello {name}"` prints the braces literally.
- **Using f-strings for text you do not control.** An f-string is code in your source file, not a template you can load at run time. Use `str.format()` or a template library for that.
- **Rounding surprises.** `f"{2.675:.2f}"` gives `2.67` for the same reason as `round()` in the numbers lesson.
- **Formatting a string with a number spec.** `f"{'abc':d}"` raises `ValueError`. The type letter must match the value.

Given `price = 1234.5` and `ratio = 0.256`, print one line using a single f-string, with a dollar sign, a thousands separator, two decimals for the price and one decimal for the percentage.

Input: none. Expected output: `$1,234.50 is 25.6% of the budget`.

<Solution>

```python title="price_share.py"
price = 1234.5
ratio = 0.256
print(f"${price:,.2f} is {ratio:.1%} of the budget")
```

```text
$1,234.50 is 25.6% of the budget
```

The `$` outside the braces is ordinary text. Inside, `,.2f` adds the separator and two decimals, and `.1%` turns `0.256` into `25.6%`.

<Exercise title="Print an aligned receipt">

Print the table below. Each row has a name, a quantity and a unit price, and the line total is quantity times price. Money has two decimals, numbers are right-aligned, and the columns are 14, 4, 9 and 9 characters wide. Use a divider line of 36 dashes.

Input: the three rows `Coffee, 2, 3.5`, `Bagel, 1, 2.25` and `Orange juice, 3, 4.0`. Expected output:

```text
Item           Qty    Price    Total
------------------------------------
Coffee           2     3.50     7.00
Bagel            1     2.25     2.25
Orange juice     3     4.00    12.00
------------------------------------
```

<Solution>

```python title="receipt.py"
name1, qty1, price1 = "Coffee", 2, 3.5
name2, qty2, price2 = "Bagel", 1, 2.25
name3, qty3, price3 = "Orange juice", 3, 4.0

total1 = qty1 * price1
total2 = qty2 * price2
total3 = qty3 * price3

print(f"{'Item':<14}{'Qty':>4}{'Price':>9}{'Total':>9}")
print("-" * 36)
print(f"{name1:<14}{qty1:>4}{price1:>9.2f}{total1:>9.2f}")
print(f"{name2:<14}{qty2:>4}{price2:>9.2f}{total2:>9.2f}")
print(f"{name3:<14}{qty3:>4}{price3:>9.2f}{total3:>9.2f}")
print("-" * 36)
print(f"{'Total':<27}{total1 + total2 + total3:>9.2f}")
```

```text
Item           Qty    Price    Total
------------------------------------
Coffee           2     3.50     7.00
Bagel            1     2.25     2.25
Orange juice     3     4.00    12.00
------------------------------------
Total                          21.25
```

The widths 14, 4, 9 and 9 add up to the 36 dashes. The header strings are quoted with single quotes so they can sit inside a double-quoted f-string on every Python version. The three rows repeat one pattern. Lesson 16 shows how a loop removes that repetition.

## Summary

- `f"...{expression:spec}..."` inserts values, and the spec controls alignment, width, precision and separators.
- `{x=}` and `{x!r}` are debugging helpers.
- <Since v="3.12" /> Quotes can be reused inside the braces, and expressions can span lines.
