After a lesson on installing packages, the useful reflex to build is the opposite one: before installing anything, check whether the standard library already does the job. It has no install step, no version conflicts, and it is documented in one place. This lesson is a guided walk past the modules you will use most. None is covered in full, because the aim is to know that each exists.

## Where to look

The reference for everything is the Library Reference at `docs.python.org/3/library/`. Each module page opens with a one-line summary, then lists functions with their signatures. Two habits make it quick to use:

- Look for the **"Added in version"** and **"Changed in version"** notes. They say when a function appeared, which matters if you must support an older Python. The module `math.integer`, for example, is marked as added in 3.15.
- Use the REPL for the details you half remember. `dir(module)` lists names and `help(module.name)` prints the documentation, as in the [beginner module lesson](../../beginner/modules-and-imports/).

Searching the docs for what you want to do, in plain words, usually finds the module faster than guessing its name.

## The system: os and sys

`os` talks to the operating system, and `sys` talks to the interpreter. These are the parts you will touch most:

```python title="os_sys.py"
import os
import sys

print(os.environ.get("NO_SUCH_VARIABLE_XYZ", "not set"))
print(os.path.join("data", "2026", "report.txt"))
print(os.path.basename("/home/you/notes.txt"))

print(sys.version_info >= (3, 11))
print(len(sys.argv))
print(sys.platform in {"linux", "darwin", "win32"})
```

```text
not set
data/2026/report.txt
notes.txt
True
1
True
```

`os.environ` is a dictionary of environment variables, so `.get` with a default is the safe way to read one. `os.path.join` builds a path with the right separator for the machine (backslashes on Windows, so the second line differs there), though `pathlib` from the files lesson is the more modern way to do the same. `sys.version_info` compares with a tuple, `sys.argv` is the list of command-line arguments (just the script name here), and `sys.platform` names the operating system.

## Files and folders: shutil

`pathlib` reads and writes single files. `shutil` handles the bigger operations, such as copying, moving and archiving. This example works in a temporary folder that is deleted afterwards, so it is safe to run:

```python title="shutil_demo.py"
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    work = Path(tmp)
    source = work / "notes.txt"
    source.write_text("remember the milk\n", encoding="utf-8")

    shutil.copy(source, work / "copy.txt")
    print(sorted(p.name for p in work.iterdir()))

    archive = shutil.make_archive(str(work / "backup"), "zip", root_dir=work)
    print(Path(archive).name)

    shutil.move(work / "copy.txt", work / "renamed.txt")
    print(sorted(p.name for p in work.iterdir()))

print(work.exists())
```

```text
['copy.txt', 'notes.txt']
backup.zip
['backup.zip', 'notes.txt', 'renamed.txt']
False
```

`shutil.copy` copies a file, `make_archive` builds a zip from a folder, and `move` renames or relocates. `tempfile.TemporaryDirectory` is a context manager from the previous module that removes the folder and everything in it on exit, which is why the last line prints `False`.

## Other programs: subprocess

`subprocess.run` starts another program, waits, and gives you its result. Pass the command as a list of strings, one per argument, rather than a single string.

```python title="subprocess_demo.py"
import subprocess
import sys

result = subprocess.run(
    [sys.executable, "-c", "print('hello from a child process')"],
    capture_output=True,
    text=True,
)
print(result.returncode)
print(result.stdout.strip())

failing = [sys.executable, "-c", "import sys; sys.exit(3)"]
print(subprocess.run(failing).returncode)

try:
    subprocess.run(failing, check=True)
except subprocess.CalledProcessError as error:
    print("failed with status", error.returncode)
```

```text
0
hello from a child process
3
failed with status 3
```

`sys.executable` is the path of the interpreter that is running, so the child uses the same Python. `capture_output=True` collects what the program prints, `text=True` decodes it into a string, and `returncode` is the exit status (zero means success). By default a failing command does not raise anything, which is easy to miss, so add `check=True` to turn a non-zero status into a `CalledProcessError`.

## Numbers: statistics, random and math

These three save you from writing numeric code that already exists and is already correct:

```python title="stats_demo.py"
import random
import statistics

scores = [70, 85, 90, 85, 60, 95]
print(statistics.mean(scores))
print(statistics.median(scores))
print(statistics.mode(scores))
print(round(statistics.stdev(scores), 2))

random.seed(11)
first = random.sample(range(100), 3)
random.seed(11)
print(first == random.sample(range(100), 3))
```

```text
80.83333333333333
85.0
85
13.2
True
```

`mean`, `median`, `mode` and `stdev` (sample standard deviation) cover the first questions anyone asks of a list of numbers. `random.seed` makes a random sequence repeatable, which is how you write a test for code that uses chance. <Since v="3.15" /> Python 3.15 adds `math.integer`, a module that gathers the exact integer functions `comb`, `factorial`, `gcd`, `isqrt`, `lcm` and `perm`:

```python title="math_integer_demo.py"
import math

try:
    from math.integer import comb, gcd, isqrt, lcm  # Python 3.15 and later
except ImportError:
    from math import comb, gcd, isqrt, lcm  # older versions

print(comb(10, 3))
print(gcd(84, 36), lcm(4, 6))
print(isqrt(50))
print(comb(10, 3) == math.comb(10, 3))
```

```text
120
12 12
7
True
```

The `try`/`except ImportError` fallback makes the file run on older versions as well: `math.integer` does not exist there, so Python raises `ModuleNotFoundError` (a kind of `ImportError`), and the names come from `math` instead. The two give the same answers, so this is only about where the names live.

## Counting: collections.Counter

A `Counter` is a dictionary that counts. Hand it any iterable and it tallies how often each item appears:

```python title="counter_demo.py"
from collections import Counter

votes = ["tea", "coffee", "tea", "juice", "tea", "coffee"]

counts = Counter(votes)
print(counts)
print(counts["tea"], counts["water"])
print(counts.most_common(2))
```

```text
Counter({'tea': 3, 'coffee': 2, 'juice': 1})
3 0
[('tea', 3), ('coffee', 2)]
```

An item that was never counted gives `0` instead of a `KeyError`. `most_common(n)` returns the `n` largest counts as `(item, count)` pairs, highest first. Items with equal counts keep the order in which they first appeared.

## Regular expressions

The `re` module finds text by pattern instead of by exact value. A **regular expression** is a small pattern language: `\d` matches one digit, `+` means "one or more of the thing before", and `\s` matches a space, tab or newline. This is a first look, enough to read the patterns in later lessons; the module has far more.

Patterns are written as **raw strings**, with an `r` before the opening quote. In a normal string, `"\t"` is already a tab before `re` sees it. In a raw string, the backslash stays a backslash, and `re` gets to interpret it:

```python title="regex_raw.py"
import re

print(len("a\tb"), len(r"a\tb"))
print(re.search(r"\d", "room 7").group())
```

```text
3 4
7
```

The normal string has three characters because `\t` is one. The raw string has four. Write every pattern as `r"..."` and backslashes always mean what the pattern language says.

`re.search` looks through a string for the first place the pattern matches. It returns a match object, or `None` when there is no match:

```python title="regex_search.py"
import re

line = "order 4521 shipped on 2026-10-12"

match = re.search(r"\d+", line)
print(match)
print(match.group())
print(re.search(r"refund", line))
```

```text
<re.Match object; span=(6, 10), match='4521'>
4521
None
```

`span` gives the start and end positions, and `.group()` gives the matched text. Because the result can be `None`, check it with `if match:` before calling `.group()` on text you did not write yourself.

`re.findall` returns every non-overlapping match as a list of strings:

```python title="regex_findall.py"
import re

line = "order 4521 shipped on 2026-10-12"

print(re.findall(r"\d+", line))
print(re.findall(r"(\d+)-(\d+)-(\d+)", line))
```

```text
['4521', '2026', '10', '12']
[('2026', '10', '12')]
```

The second pattern contains **groups**: parts in parentheses. When a pattern has groups, `findall` returns one tuple per match, holding what each group captured. The pattern matched once, so there is one tuple of three strings.

Groups are numbered from 1 in the order their opening parenthesis appears. On a match object, `.group(0)` is the whole match and `.group(1)`, `.group(2)` are the groups:

```python title="regex_groups.py"
import re

duration = "wait 90s then 15m"

match = re.search(r"(\d+)([hms])", duration)
print(match.group(0), match.group(1), match.group(2))

for amount, unit in re.findall(r"(\d+)([hms])", duration):
    print(amount, unit)
```

```text
90s 90 s
90 s
15 m
```

`[hms]` matches any one of the letters `h`, `m` or `s`. So the pattern reads a number followed by a time unit, and the loop unpacks each tuple into `amount` and `unit`.

`re.sub` replaces matches. In the replacement text, `\1` stands for what group 1 captured:

```python title="regex_sub.py"
import re

text = "call 555-0134 or 555-0188"

print(re.sub(r"\d{3}-(\d{4})", r"xxx-\1", text))
print(re.sub(r"\s+", " ", "too    many\n spaces"))
```

```text
call xxx-0134 or xxx-0188
too many spaces
```

`\d{3}` means exactly three digits. The first call hides the exchange code and keeps the last four digits through `\1`. The second collapses any run of whitespace into one space. See the [re documentation](https://docs.python.org/3/library/re.html) for the full pattern syntax.

## Command-line options: an argparse preview

`argparse` turns the strings in `sys.argv` into named, converted values and writes the `--help` text for you. This preview passes a list directly instead of reading the real command line, so that the output is fixed:

```python title="argparse_preview.py"
import argparse

parser = argparse.ArgumentParser(description="Repeat a word.")
parser.add_argument("word")
parser.add_argument("--count", type=int, default=1)
parser.add_argument("--shout", action="store_true")

args = parser.parse_args(["--count", "3", "hello"])
text = args.word.upper() if args.shout else args.word
print(" ".join([text] * args.count))

args = parser.parse_args(["--shout", "hi"])
print(args.word, args.count, args.shout)
```

```text
hello hello hello
hi 1 True
```

A bare argument (`word`) is required and positional. An option such as `--count` has a type and a default. A flag such as `--shout` is `True` when present and `False` otherwise. In a real script you call `parser.parse_args()` with no argument and it reads `sys.argv`; if the arguments are wrong, it prints a usage message and exits.

import math
import shutil
import statistics
import subprocess
import sys
import tempfile
import textwrap
from pathlib import Path

# 1. Ways to choose 3 books from 10
print(math.comb(10, 3))

# 2. Greatest common divisor of 84 and 36

## Summary

- Check the standard library before installing a package. `os`, `sys`, `shutil` and `subprocess` cover the system, `statistics`, `random` and `math` cover numbers, `Counter` tallies items, `re` finds and replaces text by pattern, and `argparse` handles command-line options.
- The Library Reference notes the version each function was added in. <Since v="3.15" /> `math.integer` is new in 3.15, and `math.comb` and friends remain available.
- `subprocess.run` does not raise on failure unless you pass `check=True`.
